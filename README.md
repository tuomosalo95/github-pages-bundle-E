# Nokian historia

## Johdanto

**Nokia** on suomalainen teknologiayhtiö, jolla on pitkä ja monivaiheinen historia. Yhtiö tunnetaan erityisesti matkapuhelimista, mutta sen historia alkoi aivan toiselta toimialalta.

Nokian kehitykseen on kuulunut esimerkiksi:

* paperiteollisuus
* kumituotteet
* elektroniikka
* matkapuhelimet
* verkkoteknologia

> Nokia on yksi Suomen tunnetuimmista teknologiayhtiöistä.

## Nokian historian tärkeimmät vaiheet

| Vuosi     | Tapahtuma                                                          |
| --------- | ------------------------------------------------------------------ |
| 1865      | Nokia perustetaan                                                  |
| 1960-luku | Nokia alkaa laajentua elektroniikkaan                              |
| 1980-luku | Matkapuhelinliiketoiminta alkaa kasvaa                             |
| 1990-luku | Nokiasta tulee maailmanlaajuisesti tunnettu matkapuhelinvalmistaja |
| 2000-luku | Nokia on yksi maailman suurimmista matkapuhelinvalmistajista       |
| 2010-luku | Matkapuhelinliiketoiminta muuttuu merkittävästi                    |
| Nykyään   | Nokia keskittyy erityisesti verkkoteknologiaan                     |

## Matkapuhelinten aikakausi

1990- ja 2000-luvuilla Nokia nousi yhdeksi maailman tunnetuimmista matkapuhelinvalmistajista. Nokian puhelimet tunnettiin esimerkiksi hyvästä kestävyydestä ja helppokäyttöisyydestä.

Tunnettuja Nokia-puhelimia olivat esimerkiksi:

1. Nokia 3310
2. Nokia 5110
3. Nokia 3210
4. Nokia N95

### Nokia 3310

**Nokia 3310** julkaistiin vuonna 2000. Puhelimesta tuli erittäin suosittu, ja sitä pidetään yhtenä Nokian tunnetuimmista puhelinmalleista.

Puhelimen tunnettuja ominaisuuksia olivat:

* hyvä akun kesto
* kestävä rakenne
* pieni koko
* tekstiviestit
* Snake-peli

## Nokia ja teknologia

Nokia ei ole nykyään ensisijaisesti matkapuhelinvalmistaja. Yhtiö keskittyy erityisesti tietoliikenneverkkoihin ja verkkoteknologioihin.

Nokian teknologiaa käytetään esimerkiksi:

* mobiiliverkoissa
* 5G-verkoissa
* tietoliikenneverkoissa
* yritysverkoissa
* pilvipalveluihin liittyvissä ratkaisuissa
